## 适用场景

搜索表单适用于**数据查询和筛选**的场景：

| 场景            | 搜索条件                       | 说明             |
| --------------- | ------------------------------ | ---------------- |
| 👤 **用户管理** | 关键词、状态、角色、注册时间   | 后台用户列表查询 |
| 📦 **订单查询** | 订单号、客户名、时间范围、状态 | 电商订单管理     |
| 📄 **日志检索** | 时间范围、操作人、操作类型     | 系统日志审计     |
| 🏷️ **商品管理** | 名称、分类、价格区间、状态     | 商品列表筛选     |
| 📊 **数据报表** | 时间维度、维度筛选             | 数据分析看板     |
| 🔐 **权限管理** | 用户名、角色、状态             | 权限分配查询     |

## 核心能力

| 特性           | 说明                                                 |
| -------------- | ---------------------------------------------------- |
| **多条件组合** | 支持 input / select / date-range / switch 多种筛选项 |
| **自动搜索**   | select/switch 变化自动触发搜索，体验流畅             |
| **手动搜索**   | 关键词输入支持回车搜索，点击按钮搜索                 |
| **条件折叠**   | 支持"展开更多"折叠复杂条件，保持界面整洁             |
| **结果展示**   | 表格展示搜索结果，支持状态标签、自定义渲染           |
| **分页控制**   | 结果自动分页，支持翻页导航                           |
| **结果计数**   | 实时显示搜索结果数量                                 |

## 设计亮点

| 亮点           | 说明                                                           | 实现方式                       |
| -------------- | -------------------------------------------------------------- | ------------------------------ |
| **多条件组合** | 支持 input / select / date-range / switch 多种筛选项，灵活组合 | `fields` 配置 + 条件渲染       |
| **自动搜索**   | select/switch 变化自动触发搜索，减少操作步骤                   | `watch` + `autoSearch` 配置    |
| **条件折叠**   | 复杂条件折叠在"更多"中，保持界面清爽                           | `more` 属性 + `showMore` 切换  |
| **实时反馈**   | 搜索状态、结果数量、加载动画，体验完整                         | `loading` + `resultCount`      |
| **结果预览**   | 表格展示 + 分页 + 自定义渲染，数据一目了然                     | `resultColumns` + `v-for` 渲染 |
| **完整交互**   | 搜索 → 结果 → 分页 → 重置，全流程闭环                          | 完整状态管理                   |
