## 核心能力

| 功能         | 说明                             |
| ------------ | -------------------------------- |
| **主表单**   | 客户名称、电话、地址等订单头信息 |
| **动态明细** | 可增删的商品行，每行独立校验     |
| **联动计算** | 单价 × 数量 = 小计，自动计算     |
| **自动汇总** | 所有明细小计自动汇总为订单总金额 |
| **完整校验** | 主表单 + 明细所有字段均可校验    |

## 适用场景

主从表单（Master-Detail Form）适用于**一对多**的数据录入场景：

| 场景            | 主表单（Master）               | 明细列表（Detail）         |
| --------------- | ------------------------------ | -------------------------- |
| 📦 **订单管理** | 客户信息、收货地址、订单日期   | 商品名称、单价、数量、小计 |
| 📄 **发票录入** | 发票号码、开票日期、购买方信息 | 项目名称、规格、金额       |
| 📋 **问卷调查** | 问卷标题、描述、发布人         | 题目列表（单选/多选/填空） |
| ✍️ **文章编辑** | 文章标题、分类、标签           | 段落、图片、附件           |
| 🏗️ **项目管理** | 项目名称、负责人、起止日期     | 任务列表、里程碑           |
| 🏥 **病历录入** | 患者信息、就诊时间、主诉       | 检查项目、用药清单         |
| 🛒 **采购订单** | 供应商信息、采购日期           | 采购物品、数量、单价       |
| 🎓 **课程设计** | 课程名称、讲师、学分           | 章节列表、课时安排         |

## 设计亮点

| 亮点             | 说明                                                        | 实现方式                                           |
| ---------------- | ----------------------------------------------------------- | -------------------------------------------------- |
| **主从结构**     | 主表单 + 嵌套动态列表，一对多数据关系在 UI 上自然呈现       | 主表单字段 + `type: 'dynamic-list'` 嵌套配置       |
| **自动联动计算** | 单价/数量变化 → 自动重算小计 → 自动汇总总金额，全链路自动化 | `watch` 深度监听 + 字段级 `handler` 联动           |
| **数据一致性**   | 主从数据统一提交，保证事务完整性                            | 单次 `onSubmit` 提交完整数据对象                   |
| **完整校验覆盖** | 主表单字段 + 明细列表所有字段均可校验，无死角               | `validateAll()` 递归校验主表单 + 动态列表          |
| **配置驱动复用** | 一套 Schema 定义主从结构，无需改动组件代码                  | `FormSchema` + `dynamicConfig.itemSchema` 双层配置 |
| **实时反馈**     | 明细变化即时更新汇总，用户所见即所得                        | `watch` + `onChange` 事件驱动                      |
