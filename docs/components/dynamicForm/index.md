# 📝 表单组件

> 一套基于 Vue 3 + TypeScript 构建的企业级动态表单组件库，覆盖 80% 以上后台表单场景。

## 概述

本模块提供了 **9 种** 核心表单组件，从基础的动态表单到复杂的树形表单、可编辑表格，满足不同业务场景的需求。

## 组件列表

| 组件 | 说明 | 复杂度 | 适用场景 |
|------|------|--------|----------|
| [基础表单](./basic-form) | 标准数据录入，支持 input / textarea / select / radio / checkbox / switch | ⭐ | 用户注册、登录、个人中心、联系表单、企业信息录入 |
| [动态字段表单](./dynamic-field-form) | 字段联动、条件显示/隐藏、动态禁用、动态必填 | ⭐⭐⭐ | 商品发布、会员注册、租房信息、物流配置、活动报名、优惠券配置 |
| [动态列表表单](./dynamic-list-form) | 支持增删条目，每个条目独立校验、独立数据 | ⭐⭐⭐⭐ | 订单明细、地址管理、问卷配置、标签管理、家庭成员、教育经历、工作经历、数据录入 |
| [主从表单](./master-detail-form) | 主表单 + 嵌套动态列表，一对多数据关系 | ⭐⭐⭐⭐⭐ | 订单管理、发票录入、问卷调查、文章编辑、项目管理、病历录入、采购订单、课程设计 |
| [分步表单](./step-form) | 长表单拆分为多个步骤，分步校验和提交 | ⭐⭐⭐⭐ | 商品发布、用户注册、项目创建、问卷调查、课程创建、病历录入 |
| [表格编辑表单](./editable-table) | 表格展示 + 行内编辑 + 批量操作 + 导出 | ⭐⭐⭐⭐ | 商品管理、用户管理、数据录入、配置管理、报表数据、优惠券管理 |
| [搜索表单](./search-form) | 多条件组合搜索 + 结果展示 + 分页 | ⭐⭐⭐ | 用户管理、订单查询、日志检索、商品管理、数据报表、权限管理 |
| [卡片表单](./card-form) | 字段按卡片分组展示，可折叠展开 | ⭐⭐ | 个人设置、企业信息、系统配置、主题定制、商品编辑、用户档案 |
| [树形表单](./tree-form) | 无限层级树形结构，支持增删改、排序、展开/收起 | ⭐⭐⭐⭐⭐ | 商品分类、组织架构、权限管理、目录管理、标签体系、地区管理 |
