## 适用场景

分步表单适用于**长表单、多模块、复杂录入**的场景：

| 场景            | 步骤划分                         | 说明             |
| --------------- | -------------------------------- | ---------------- |
| 📦 **商品发布** | 基本信息 → 规格参数 → 图片与发布 | 电商后台商品录入 |
| 📝 **用户注册** | 个人信息 → 账号设置 → 完成       | 多步骤注册流程   |
| 🏗️ **项目创建** | 项目信息 → 团队配置 → 权限设置   | 复杂项目管理     |
| 📄 **问卷调查** | 基本信息 → 核心问题 → 补充信息   | 长问卷拆分       |
| 🎓 **课程创建** | 课程信息 → 章节配置 → 发布设置   | 在线教育后台     |
| 🏥 **病历录入** | 患者信息 → 检查项目 → 诊断结论   | 医疗信息系统     |

## 核心能力

| 特性           | 说明                                         |
| -------------- | -------------------------------------------- |
| **步骤指示器** | 可视化展示当前进度，支持跳转已完成步骤       |
| **分步校验**   | 每步独立校验，只有当前步骤通过才能进入下一步 |
| **全部校验**   | 提交时校验所有步骤，自动跳转到第一个错误步骤 |
| **数据保留**   | 步骤切换时数据自动保留，可随时返回修改       |
| **平滑过渡**   | 步骤切换带动画效果，体验流畅                 |
| **完整提交**   | 所有步骤通过后统一提交，数据完整             |

## 配置示例

```typescript
const stepSchema: FormSchema = {
  title: '📋 商品发布向导',
  steps: [
    { key: 'step1', title: '基本信息', icon: '📝' },
    { key: 'step2', title: '规格参数', icon: '⚙️' },
    { key: 'step3', title: '图片与发布', icon: '🚀' }
  ],
  fields: [
    { key: 'name', type: 'input', label: '商品名称', step: 'step1', required: true },
    { key: 'price', type: 'number', label: '价格', step: 'step2', required: true },
    { key: 'specs', type: 'dynamic-list', label: '规格参数', step: 'step2' },
    { key: 'images', type: 'input', label: '商品图片', step: 'step3' }
  ]
}
```

## 设计亮点

| 亮点             | 说明                                                         | 实现方式                                                |
| ---------------- | ------------------------------------------------------------ | ------------------------------------------------------- |
| **用户体验优先** | 长表单拆分为小步骤，降低认知负担，用户无需面对冗长的滚动页面 | 步骤指示器 + 分步面板切换                               |
| **渐进式填写**   | 用户专注于当前步骤，减少干扰，每一步只展示相关字段           | 每步独立渲染字段，其他步骤隐藏                          |
| **智能跳转**     | 提交时自动定位到有错误的步骤，无需用户手动排查               | `validateStep()` 逐步骤校验 + 自动跳转                  |
| **进度可见**     | 步骤指示器让用户清晰了解完成进度，已完成/当前/未完成状态区分 | 步骤状态：`is-active` / `is-completed` / `is-clickable` |
| **配置驱动**     | 步骤配置与字段配置分离，灵活组合，新增步骤无需改动组件代码   | `steps` + `step` 字段属性配置                           |
