## 适用场景

普通表单适用于**标准的数据录入**场景：

| 场景            | 典型字段                         | 说明          |
| --------------- | -------------------------------- | ------------- |
| 📝 **用户注册** | 用户名、邮箱、密码、确认密码     | 基础信息收集  |
| 🔑 **登录表单** | 账号、密码、验证码               | 身份验证      |
| 👤 **个人中心** | 昵称、头像、简介、性别           | 个人信息编辑  |
| 📞 **联系表单** | 姓名、电话、邮箱、留言内容       | 用户反馈/咨询 |
| 🏢 **企业信息** | 公司名称、统一社会信用代码、地址 | 企业资质录入  |
| 📋 **问卷调查** | 单选、多选、评分、文本输入       | 用户调研      |

## 核心能力

| 特性         | 说明                                                  |
| ------------ | ----------------------------------------------------- |
| **基础输入** | input / textarea / select / radio / checkbox / switch |
| **实时校验** | 必填、长度、格式（手机号/邮箱/正则）                  |
| **实时反馈** | 输入即校验，错误提示即时显示                          |
| **提交拦截** | 校验失败时自动拦截，滚动到第一个错误字段              |
| **重置功能** | 一键清空所有字段，恢复默认值                          |

## 设计亮点

| 亮点         | 说明                                       | 实现方式                                 |
| ------------ | ------------------------------------------ | ---------------------------------------- |
| **即时反馈** | 输入即校验，错误提示实时显示，无需等待提交 | `@blur` + `@input` 实时触发校验          |
| **智能拦截** | 提交时自动拦截所有未通过校验的字段         | `validateAll()` + `scrollToField()`      |
| **精准定位** | 校验失败时自动滚动到第一个错误字段并高亮   | `scrollToField()` + `focus()` + 高亮动画 |
| **视觉清晰** | 错误状态、帮助文本、必填标识一目了然       | 统一的设计规范：红色错误 / 灰色帮助      |
| **配置驱动** | 所有字段、校验、联动由 Schema 定义         | 纯 JSON 配置，无需硬编码                 |
