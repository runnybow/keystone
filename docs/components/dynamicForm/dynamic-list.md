## 适用场景

动态列表表单适用于**收集多组相同结构数据**的场景：

| 场景            | 列表内容                       | 说明                       |
| --------------- | ------------------------------ | -------------------------- |
| 📦 **订单明细** | 商品名称、单价、数量、小计     | 一个订单包含多个商品       |
| 📍 **地址管理** | 省份、城市、详细地址、是否默认 | 用户可维护多个收货地址     |
| 📋 **问卷配置** | 题目、选项类型、是否必答       | 一份问卷包含多道题目       |
| 🏷️ **标签管理** | 标签名称、颜色、分类           | 文章/商品可打多个标签      |
| 👨‍👩‍👧‍👦 **家庭成员** | 姓名、关系、年龄、联系方式     | 用户档案中的家庭成员列表   |
| 🎓 **教育经历** | 学校、专业、学历、起止时间     | 个人简历中的教育背景       |
| 💼 **工作经历** | 公司、职位、起止时间、离职原因 | 个人简历中的工作履历       |
| 📊 **数据录入** | 多行数据批量录入               | 报表数据、配置数据批量导入 |

## 核心能力

| 特性         | 说明                                                |
| ------------ | --------------------------------------------------- |
| **动态增删** | 点击按钮新增条目，每个条目独立删除（保留最少 1 项） |
| **数量限制** | 可配置最小/最大条目数（如 1-10 项）                 |
| **独立校验** | 每个条目内的字段独立校验，互不影响                  |
| **独立数据** | 每个条目的数据独立存储，互不干扰                    |
| **完整校验** | 提交时校验所有条目的所有字段                        |
| **一键重置** | 重置时恢复到初始条目数（默认 1 项）                 |
| **数据预览** | 每个条目单独显示数据预览，方便调试                  |

## 设计亮点

| 亮点           | 说明                                    | 实现方式                               |
| -------------- | --------------------------------------- | -------------------------------------- |
| **数据隔离**   | 每个条目独立存储数据，互不影响          | 数组索引 + 独立数据对象                |
| **独立校验**   | 每个条目内的字段独立校验，错误互不干扰  | 条目级 `validate()` + 独立 `fieldRefs` |
| **灵活控制**   | 可配置最小/最大条目数，适应不同业务约束 | `minItems` / `maxItems` 配置           |
| **完整交互**   | 增 → 填 → 删 → 校验 → 提交，全流程闭环  | 增删方法 + 校验 + 提交拦截             |
| **可视化预览** | 每个条目独立显示数据预览，方便调试      | 条目级 `item-preview`                  |
