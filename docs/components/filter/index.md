# 🔍 筛选器组件

> 一套基于 Vue 3 + TypeScript 构建的企业级筛选器组件库，从简单查询到 AI 智能解析，覆盖全场景数据筛选需求。

## 概述

本模块提供了 **5 种** 核心筛选器组件，从基础的固定字段筛选到 AI 驱动的自然语言筛选，满足不同复杂度的数据查询场景。

## 组件列表

| 组件 | 说明 | 复杂度 | 适用场景 |
|------|------|--------|----------|
| [基础筛选器](./basic-filter) | 固定字段 + 固定操作符 | ⭐ | 简单列表查询 |
| [动态筛选器](./dynamic-filter) | 可增删条件行，自由组合 | ⭐⭐⭐ | 灵活查询、多条件筛选 |
| [分组筛选器](./group-filter) | AND / OR 逻辑分组 | ⭐⭐⭐⭐⭐ | 复杂业务规则查询 |
| [保存筛选器](./saved-filter) | 保存 / 加载 / 管理筛选方案 | ⭐⭐⭐⭐ | 重复查询场景 |
| [智能筛选器](./smart-filter) | 自然语言 + AI 解析 | ⭐⭐⭐⭐⭐ | 用户友好型查询 |
